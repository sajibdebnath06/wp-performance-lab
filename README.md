# WP Performance Lab

A practical SEO, AEO and GEO portfolio project.

## Project Overview

This project documents the development and optimization
of a website focused on WordPress performance.

## Objectives

1. Build a search engine friendly website.
2. Conduct keyword and competitor research.
3. Implement technical and on page SEO.
4. Improve content clarity for answer engines.
5. Investigate visibility in AI search tools.
6. Measure results using real data.

## Tools

- GitHub Pages
- Google Search Console
- Google Analytics 4
- Google Trends
- Lighthouse
- Screaming Frog
- Bing Webmaster Tools
